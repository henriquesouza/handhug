# ![](./static/icon-48x48.png) HandHug

HandHug is a private social media platform meant to encourage offline socialization. 

## Features

**Private communities:** gather members of your community in one place and engage in enriching discussions.

**Moderation tools:** ensure your community has access to a safe and respectful environment with built-in moderation tools and user authority levels.

**Events:** schedule events for your community and take advantage of confirmation and notification features.

**Statistics**: get anonymous numbers about community engagement on and offline.


## Stack

- Python 3.13
- Django 6.1
- PostgreSQL 16
- Docker
- Kubernetes
- RabbitMQ
- Redis
- Terraform
- Cognito
- SonarQube
- Floci (AWS simulation)
